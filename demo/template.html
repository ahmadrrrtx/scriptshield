Research overview

The problem

Most Urdu typed on phones is Roman Urdu: Urdu in Latin letters. Safety evaluations usually treat Urdu as one language. If a model refuses a harmful request in Urdu script but not when the same sentence is typed in Latin letters, the guardrail has a hole where everyday Urdu is written.

    Method in brief

      How to read the labels

      • judge: the label of the automatic guard model, fixed before the experiment. It is unreliable for Roman-Urdu replies.
      • read as: an LLM agent read the Roman-Urdu replies of four arms one by one, with the arm hidden. Not a human annotation.
      • withheld: the reply to a harmful request is not shown unless it is a clean refusal. Its label, length and hash are published.
