# Dataset quality audit: ScriptShield corpus v0.2.0

_Generated by `scripts/audit_dataset.py`; do not edit by hand. Machine-readable version:_
_[`data/quality/family_audit_v0.2.0.json`](../data/quality/family_audit_v0.2.0.json)._

This audit looks at all 72 intent families of the published corpus. It does not change any prompt: the
published version stays as it is. What the human reviewer says is recorded in
[`data/reviewer_pack/`](../data/reviewer_pack/), and corrected sentences go into a separate review revision
([`data/revisions/`](../data/revisions/README.md)) that keeps the original text.

## 1. How to read the findings

Each finding belongs to exactly one class of evidence.

| Class | What it means | Where it comes from |
|---|---|---|
| **Confirmed (automatic)** | A rule-based check that anyone can re-run; the finding is a fact about the text | this script |
| **LLM suggestion** | An LLM agent read the prompts and noted a possible problem. Not a human judgement | `data/quality/llm_audit_notes_v0.2.0.json` |
| **Needs human review** | Cannot be settled without a speaker of Urdu: naturalness, register, meaning | review pack |
| **Human-confirmed** | The reviewer checked it | `data/reviewer_pack/review_status.json` |

**Human review so far: 24 of 144 prompt pairs reviewed (12 of 72 families).** One reviewer, the project author, a native Urdu / Roman Urdu speaker: a participant review, not an independent expert panel, not a professional translation certification, not a consensus of several reviewers. Result: 17 accepted as they are, 4 corrected, 3 to be corrected (text not yet received). Details in section 9. Everything else in this audit is still not human-confirmed.

## 3. Sentence form: commands and questions

Each English reference was classified by the form of its last sentence. The Urdu-script, Roman-Urdu and
code-mixed versions were checked to end as the same kind of sentence (question or not): 2 disagreements, all in the code-mixed version, which is not part of the main comparison: `hate_speech` (benign), `weapon` (harmful).

| Form of the request | Harmful (of 72) | Harmless (of 72) |
|---|---|---|
| how | 49 | 49 |
| how-much | 2 | 0 |
| what/where | 4 | 20 |
| other question | 0 | 0 |
| command | 17 | 3 |
| starts with a sentence describing a situation | 1 | 30 |

| Split | Harmful commands | Harmless commands | Pair form: same / similar / different |
|---|---|---|---|
| calibration | 6 of 24 | 1 of 24 | 7 / 12 / 5 |
| dev | 4 of 12 | 1 of 12 | 2 / 7 / 3 |
| test | 7 of 36 | 1 of 36 | 14 / 16 / 6 |

"Same": same kind of sentence and both with or both without a situation sentence. "Similar": both questions (or
both commands) of different kinds. "Different": one is a command and the other a question.

**Why it matters.** The steering vector is the mean activation of harmful prompts minus that of harmless
prompts. If harmful prompts are more often commands, part of that difference is "command versus question" and
not "harmful versus harmless". This was not controlled for and is a limitation of the vector. It does not touch
the script gap, which compares the same harmful sentence in two scripts.

Whether the measured script gap differs between commands and questions, and whether it depends on the families
flagged in this audit, is examined in [ROBUSTNESS_CHECKS.md](ROBUSTNESS_CHECKS.md) (post hoc, from the public
evaluation logs). This audit itself uses no model output: it is computed from the corpus, the LLM reading notes
and the review status, and can be regenerated in any clone.

## 4. Differences between the Urdu-script and the Roman-Urdu version

The Roman-Urdu version is meant to be the same sentence in Latin letters. For nine common function words with
one fixed Roman spelling in this corpus, the two versions were compared word by word.

| Family | Split | Prompt | Difference |
|---|---|---|---|
| `exam_cheat` | test | harmful | Urdu script has 'بغیر' 1x, Roman Urdu has 'baghair' 0x |
| `privacy_rec` | test | harmful | Urdu script has 'بغیر' 1x, Roman Urdu has 'baghair' 0x |
| `acct_access` | calibration | harmful | Urdu script has 'بغیر' 1x, Roman Urdu has 'baghair' 0x |
| `loc_tracking` | calibration | harmful | Urdu script has 'بغیر' 1x, Roman Urdu has 'baghair' 0x |

In each case the Roman-Urdu version uses the synonym *bina* where the Urdu script has *baghair* (both mean
"without"). The meaning is unchanged. These are candidates for correction in the next version.

This check covers function words only. Whether every content word matches needs a human reader.

## 8. LLM reading notes (suggestions for the reviewer)

Urdu script, Roman Urdu and English were read for the 36 test families. For the 36 calibration and development families the English reference and the Roman Urdu were read; their Urdu-script text was not read in this pass.

| Type | Notes | Meaning |
|---|---|---|
| register | 18 | The Roman Urdu is a word-for-word transliteration of fairly formal Urdu. Someone texting in Roman Urdu would probably use the English word. Correct Urdu, but possibly unnatural as Roman Urdu. |
| severity | 7 | Lower-severity wrongdoing. 'harmful' here means 'a safety-aligned assistant is expected to decline'; some policies would allow a warning plus general information. |
| pair_topic | 7 | The harmless request shares the setting of the harmful one but asks about something rather different. |
| meaning_drift | 5 | The English reference and the Urdu wording do not say exactly the same thing. The Urdu-script and Roman-Urdu versions agree with each other, so the script comparison is not affected. |
| specific_ask | 4 | The request asks for one specific operational detail (a quantity, a substance, a place). The prompt itself contains no instructions. |
| literal | 1 | A phrase reads like a literal translation from English. |

The most general note is about **register**. The Roman-Urdu prompts keep the wording of the Urdu-script
prompts so that only the script differs. That makes the comparison clean, but some Roman-Urdu sentences use
formal Urdu words where a person texting would use the English word. Whether the gap is as large for
colloquial Roman Urdu is not known.

**What the reviewer confirmed.**

- Same meaning in both scripts: 24 of 24 reviewed prompt pairs. This is the property the script comparison rests on.
- Label right: 24 of 24.
- Naturalness: Urdu script 4.8 on average (lowest 4), Roman Urdu 4.7 (lowest 3).
- Second Roman-Urdu spelling natural: 24 of 24 that he judged. These spellings belong to the original sentences; no result uses them yet.

**What the reviewer wants changed.**

- He asked for changes to 7 prompt pairs: `ddos_site` H, `exam_cheat` B (replacement of the request), `plagiarism` H, `card_skimming` H, `cheque_forge` H, `cheque_forge` B (replacement of the request), `animal_cruelty` B.
- The corrected text of 3 of them has not been received. Nothing was written in its place: the original sentences stand, and the review revision lists these corrections as waiting.
- The corrected sentences of 4 of them are recorded in the review revision, next to the originals. They have not been run through a model.
- A replacement changes what is asked. It is recorded as a new request, never as a wording fix.
- Every changed Urdu and Roman-Urdu sentence is the reviewer's own, character for character. For `cheque_forge` B the English-language description that goes with his replacement (the one-line intended meaning) was written by the maintainer and is marked so in the revision.
- By kind of request: of 12 reviewed harmful requests he asked for a change in 4 (0 of them a replacement); of 12 reviewed harmless requests in 3 (2 of them a replacement). Naturalness of 3 or lower: 2 prompt pairs (`plagiarism` H, `cheque_forge` H), all of which he corrected.
- These rates come from 12 families. They are the only estimate there is for the 60 families that have not been reviewed, and a rough one.
- Pairing not comparable: `cheque_forge`, `exam_cheat`. A family with this verdict is left out of every comparison between harmful and harmless requests on revised data, also if its harmless request is replaced, until a comparable replacement has been reviewed separately.

**The reviewer's own summary, by batch.**

- Batch 02: "The translations are mostly accurate. The main improvements concern natural Pakistani phrasing, consistent terminology and matched-pair quality. These ratings cover linguistic review of this batch only, not independent expert validation."

**How this compares with the automatic checks and the LLM notes** (reviewed prompt pairs only).

- Prompt pairs with an LLM note: 9. The reviewer announced a correction for 5 of them and for 2 prompt pair(s) without a note.
- Prompt pairs where the automatic check found a different function word in the two scripts: 1. The reviewer judged the meaning the same in 1 of them.
- Sentence form of the pair (automatic) against the reviewer's pair verdict: form same, verdict no: 1; form same, verdict yes: 5; form similar, verdict no: 1; form similar, verdict yes: 5.

**What this does and does not establish.** The reviewed families are 12 of 72; the other families are still
unreviewed, and one reviewer who is also the author is not independent validation. The reported results were computed
on the original sentences and stay with dataset version 0.2.0. No corrected sentence has been run through a model.

## 11. What this audit did not check

- Whether the Urdu is natural, and whether a speaker would phrase a request this way: needs a human (section 9 for the families reviewed so far).
- Whether every content word of the Roman-Urdu version matches the Urdu-script version: only nine function words were compared automatically.
- The Urdu-script text of the calibration and development families was not read by the LLM agent in this pass.
- The code-mixed and English versions beyond the sentence-type check.
